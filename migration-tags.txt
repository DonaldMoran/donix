# migration-tags.txt — A1–A5 working tag map (dons-os → donix)
#
# The 56 local-only working tags created during the newlib-to-musl
# migration.  They may be deleted before the public push; this file
# preserves the name-to-commit mapping so tag names referenced in
# handoff.md and ROADMAP.md stay resolvable.
#
# Format: tag  commit-SHA  commit subject
#
# The SHA is the commit the tag points at, not the tag object's own
# SHA.  Some tags are annotated (git cat-file -t <tag> reports
# "tag"); for those, the annotated tag object has its own SHA which
# is not listed here.  Resolve a tag to its commit with either:
#     git rev-list -n1 <tag>
#     git log -1 <commit-SHA>
#
# Two naming schemes appear:
#   YYYYMMDDA..Z    pre-A5, one letter per commit per day
#   YYYYMMDD-NN     A5, two-digit sequence per day
# The numeric scheme was introduced at 20260926Z because the letter
# scheme was exhausted (Z is the last letter).
#
# These are NOT the release tags.  The dons-os version tags
# (v0.0.1 through v0.5.4) and the donix migration-completion tag
# (v0.5.5) remain as real git tags.
#
# Reconstruct the file after tag deletion:
#     git log --format='%h %s' <commit-SHA>
